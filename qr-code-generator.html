About the QR Generator

Whether it's a link, a WiFi password, or a plain text message, QR Generator turns it into a scannable code you can customize and download — no signup, no watermark, no daily limit.

Features

  • Custom foreground and background colors
  • Adjustable size from 120px to 480px
  • Download as PNG or true vector SVG
  • Works with any link or plain text

How to Use

Type or paste a link or text, adjust the foreground/background colors and size, then tap Generate code. Download as PNG for web use or SVG for print and scaling.

Benefits

  • SVG export scales to any size without losing quality — ideal for print
  • No account or watermark, unlike many free QR generators
  • Generated entirely in your browser, nothing sent to a server

Making a QR code that scans reliably

  • Keep contrast high. Dark code on a light background scans best; inverted or low-contrast colour pairs fail on many phones.
  • Leave a quiet zone. Keep a blank margin around the code and do not crop into it.
  • Size matters. For print, aim for at least 2 cm (about 0.8 inch) per side, and larger for posters or scanning from a distance.
  • Shorter content scans faster. A short link produces a simpler, more forgiving pattern than a long one.

Always test with two different phones before printing a large batch.

PNG or SVG?

PNG suits websites, documents and chat. SVG is a vector file that scales to any size without blurring, so it is the right choice for business cards, flyers, packaging and large posters. If a printer asks for a vector, send the SVG.

Static codes and good uses

The codes created here are static: the link or text is encoded directly in the pattern, so they never expire and need no account, but you cannot change the destination later. If you need to edit a destination or track scans, read our guide on dynamic vs static QR codes. Popular uses include menus, Wi-Fi details written as text, event links, portfolio pages and contact information. Test the link first, and use https addresses so visitors do not see browser warnings. To brand a printed handout, add a mark with Image Watermark, or put codes into a document with Image to PDF. Codes are generated in your browser and nothing is sent to a server.

Frequently Asked Questions

What's the difference between PNG and SVG export?
PNG is a fixed-resolution image, good for web use. SVG is a vector format that scales to any size — print-ready — without losing sharpness.

Is there a limit to how much text I can encode?
QR codes can hold a few thousand characters, but very long text produces a denser, harder-to-scan code — shorter links or text scan more reliably.

About the Merge PDF

Whether you're combining scanned receipts, assembling a report from separate chapters, or stitching signed pages back into one contract, Merge PDF combines any number of PDF files into a single document — reordered exactly how you want, processed entirely in your browser. See our full guide to merging PDFs online for a step-by-step walkthrough.

Features

  • Drag and drop multiple PDF files at once
  • Reorder files before merging by dragging them into place
  • Live file count and total page count
  • One-click merge and download

How to Use

Drag in all the PDF files you want combined, or tap to browse. Drag the files into the order you want the final document to read in, then tap Merge & download.

Benefits

  • Files are never uploaded — merging happens locally in your browser
  • No file size limits imposed by a server, no daily quota
  • Works identically on desktop and mobile

When merging PDFs saves time

  • Applications and forms: combine a CV, cover letter, certificates and ID scans into one upload that portals accept.
  • Finance and admin: bundle monthly receipts or invoices into a single file for an expense claim or accountant.
  • Contracts: reunite a signed signature page with the main agreement.
  • Study and reports: merge chapters, lecture notes or appendices into one document with continuous page order.

Getting the order right

The final document follows the order of the list, so drag files into place before you press Merge & download. Name your files with numbers (01-cover, 02-report) so they sort correctly when you select several at once. The page count shown above the list is a quick check that nothing was missed: it should equal the sum of the pages in your source files. If the combined file is too large to email, run it through PDF Compress afterwards.

Troubleshooting and next steps

Merging keeps pages exactly as they are, so mixed page sizes (A4 next to Letter) stay mixed. If one file will not load, it is probably password-protected: remove the password with Unlock PDF first, provided you have the password. To pull a few pages out of a large file before merging, use Split PDF. When you are done and need to restrict access, Protect PDF adds a password to the merged result. For a longer walkthrough see our guide on how to merge PDF files online, or compare options in Best Free PDF Tools.

Frequently Asked Questions

Is there a limit to how many PDFs I can merge?
Browser-based merging is limited by your device's memory rather than a fixed count — a handful of files works instantly, while dozens of very large files may be slower.

Will merging affect the quality of my PDFs?
No — merging combines pages as-is; it doesn't re-render or re-compress content, so text and images stay exactly as sharp as the originals.

Can I merge password-protected PDFs?
Most browser-based mergers, including this one, can't read encrypted PDFs directly — remove the password first using a PDF editor, then merge.
